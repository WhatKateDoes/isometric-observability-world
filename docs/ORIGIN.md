# Origin

Generalised from a private "isometric observability world" skill whose reference implementation was a starship that
shows what two home-lab AI servers are doing. This repository contains none of that project's art, names, hostnames or
network layout: it keeps the idea (services as buildings, load as light, traffic as crates, workers as crew) and the
discipline (a hard boundary around the telemetry file, art that is checked by looking at it).
